Syntax Breakdown: "Hello World" Anatomy

  • public: Access modifier allowing the class to be accessed from anywhere.
  • class: Blueprint container for code (variables and methods). File name must match class name (e.g., Demo.java & public class Demo).
  • { } (Body Brackets): Encloses the class or method contents ("opens and closes the box").
  • public static void main(String[] args): Entry point door for Java execution. Java enters the program through main().
  • System.out.println(): Prints text to the screen (out) and moves to a new line.
  • ; (Semicolon): Statement terminator marking the end of an instruction.

Java Loops Summary

Loop Type Best Used When Condition Check
for Loop The exact number of iterations is known in advance. Entry-controlled (Checks condition before executing body)
while Loop The number of iterations depends on a condition being true. Entry-controlled (Checks condition before executing body)
do-while Loop The code block must execute at least once regardless of condition. Exit-controlled (Checks condition after executing body)

Day 04 Practice Programs

1. Printing Numbers 1 to 5 using for, while, and do-while:

public class LoopsDemo {
    public static void main(String[] args) {
        // 1. for loop
        System.out.println("--- for Loop ---");
        for (int i = 1; i <= 5; i++) {
            System.out.println("Count: " + i);
        }

        // 2. while loop
        System.out.println("--- while Loop ---");
        int j = 1;
        while (j <= 5) {
            System.out.println("Count: " + j);
            j++;
        }

        // 3. do-while loop
        System.out.println("--- do-while Loop ---");
        int k = 1;
        do {
            System.out.println("Count: " + k);
            k++;
        } while (k <= 5);
    }
}

Day 06 Practice Code

1. Student Class with Constructor & this Keyword:

public class Student {
    int age;
    String name;

    // Parameterized Constructor initializing instance attributes
    Student(int age, String name) {
        this.age = age;   // 'this.age' refers to instance variable, 'age' refers to parameter
        this.name = name; // 'this.name' refers to instance variable, 'name' refers to parameter
    }

    void display() {
        System.out.println(this.age + " " + this.name);
    }

    public static void main(String[] args) {
        Student s1 = new Student(20, "Ajay");
        s1.display(); // Output: 20 Ajay
    }
}
