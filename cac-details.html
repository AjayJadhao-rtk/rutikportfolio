2D Vector Export & File Formats for Cutting

Learned the workflows for translating CAD designs into machine-readable 2D vector files for Laser Cutters, CNC Routers, and Vinyl Cutters. Explored the key file formats used in Computer Aided Cutting.

DXF / DWG Export SVG Vectors Kerf Compensation Laser & CNC Prep

Common Export File Formats

Format Full Name Primary Use Case
DXF Drawing Exchange Format Standard 2D vector export for Laser Cutters, CNC Routers, and Waterjets.
SVG Scalable Vector Graphics 2D vector cutting for desktop vinyl plotters, laser engravers, and web graphics.
DWG Drawing File Native AutoCAD 2D/3D format used for detailed engineering blueprints.
STEP / IGES Standard for Exchange of Product Data 3D neutral format used when sending 3D models to CAM software for CNC milling.
Project

Door Locking System — Upper Faceplate Layout

Designed a 2D cut layout for the upper faceplate of an automated Door Locking System in Autodesk Fusion. The layout incorporates mounting cutouts and text labels for electronic components including an ESP8266 Wi-Fi module, a SG90 Micro Servo motor, and 18650 Lithium-Ion Battery holders.

Faceplate Design Component Mounting Cutouts Laser Engraving Text Enclosure Layout

Design Features & Layout Details

  • ESP8266 Slot: Rectangular cutout designed for mounting the Wi-Fi microcontroller board.
  • Micro Servo SG90: Circular and rectangular mounting slots created for the locking mechanism actuator.
  • 18650 Battery Slots: Cutout profiles and engraved text labels for the dual 18650 Lithium-Ion battery power source.
  • Laser Engraved Labels: Applied text profiles onto the faceplate to mark component placement during physical assembly.
