OSI Model Layer Breakdown

Layer Data Unit Primary Role & Protocols
1. Application Data User interface; uses SMTP, FTP, HTTPS protocols.
2. Presentation Data Data formatting, encryption, and compression (e.g. Zip).
3. Session Data Establishes, maintains, authenticates, and authorizes sessions.
4. Transport Segments TCP (feedback/confirmation) & UDP (no feedback); error checking.
5. Network Packets Handles IP addresses and packet routing across networks.
6. Data Link Frames Manages physical (MAC) addresses and flow control.
7. Physical Bits Physical bit transmission via hardware (Hubs, Cables, Switches).

Assessment Questions & Answers

# Question Answer / Explanation
1 Why do we use Loops in programming? To execute a block of code repeatedly based on a condition without rewriting code manually, saving time and memory.
2 Which file formats are used to export for Laser Cutting? 2D vector formats like DXF and SVG, as well as DWG files.
3 What is the difference between a Class and an Object in Java? A Class is a blueprint/template, while an Object is a real instance created from that blueprint.
4 What is the primary role of a Router in networking? To connect different networks together and route data packets to their target IP destinations.
5 What does the this keyword do in Java? Refers to the current class instance/object and helps resolve variable shadowing when parameter names match instance variables.
6 What is the purpose of the ping command? Uses ICMP echo messages to test network connectivity, latency, and reachability to a remote IP address.

WebSockets HTTP Handshake WebRTC Peer-to-Peer (P2P)

Real-Time Technologies Comparison

Feature WebSockets WebRTC
Primary Purpose Bidirectional text/data streaming over single TCP connection. Real-time peer-to-peer audio, video, and data transmission.
Architecture Client-Server (TCP based). Peer-to-Peer (P2P) directly between browsers.
Handshake / Setup HTTP Upgrade header initiates protocol switch. Uses signaling servers (STUN/TURN) to establish direct paths.
Use Cases Live chat apps, real-time dashboards, notification feeds. Video conferencing (Zoom/Meet in browser), P2P file sharing.
